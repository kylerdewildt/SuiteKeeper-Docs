# SuiteKeeper Privacy Policy

Last updated: September 20, 2026

SuiteKeeper (previously named SuiteLedger) is a Chrome extension developed by Kyler DeWildt for documenting NetSuite customizations in a local project inventory. This policy describes the data handled by SuiteKeeper 1.5.

## Information the extension handles

SuiteKeeper handles information you enter, import from a backup, or request it to capture from a supported NetSuite setup page. This can include:

- Project names, descriptions, and environments.
- Object names and types, script or field IDs, internal IDs, field categories and data types, applicable records, and selected configuration settings.
- NetSuite account identifiers, owner names, and source-page URLs associated with captured objects.
- Notes, dependencies, tags, work status, change descriptions, and saved edit history.
- Preferences such as appearance, capture behavior, and the capture button's visibility and position.

The extension's on-page control loads on supported NetSuite setup pages. Configuration values are read when you request a capture. The extractor reads recognized controls, excludes password and identified credential/token controls, and removes unrelated query parameters from automatically captured source URLs. SuiteKeeper does not access browser cookies or continuously record your browsing history.

## How information is used

Information is used to provide the project inventory, capture review and quick save, search and filtering, edit history, exports, backups, and your chosen interface settings. Names and account identifiers are used as documentation you can view and edit, not to create advertising profiles.

## Storage and retention

Saved inventory and preferences are stored in the extension's local storage in your Chrome profile. They are not automatically synchronized to other computers or Chrome profiles by SuiteKeeper. Temporary capture drafts use Chrome session storage and are subject to a 24-hour expiry check; they also end when the browser session ends. The extension retains up to 25 saved edit-history entries per item.

Saved items remain until you delete them or remove the extension's data. You can review, edit, and delete items in the workspace. Deleting an item removes its retained history from the current inventory. Empty projects can also be deleted. Uninstalling the extension removes its local inventory and preferences. The developer does not hold a server copy and cannot recover removed local data.

## Exports, backups, and sharing

When you request an export or backup, SuiteKeeper creates a CSV, Word, or JSON file for you to download. Importing a backup reads the file you select. Downloaded files remain under your control; deleting data in the extension does not delete those files. If you save them in a folder synchronized by another service, that service may synchronize the files according to your settings.

SuiteKeeper does not transmit your inventory to the developer or an external service. It does not include analytics, advertising, or remote executable code. It does not sell your data or automatically share it with NetSuite Full Tools or other extensions. You decide whether to share downloaded files.

## Limited use

SuiteKeeper's use of information follows the Chrome Web Store User Data Policy, including its Limited Use requirements. Information is used only for the extension's stated documentation features. It is not sold, used for advertising, used for unrelated profiling, or used to determine creditworthiness or for lending purposes.
